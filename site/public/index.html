Why Confidant

A memory that stays yours.

A simple home for relationship context, with useful tools for you and your agents.

1

Plain files

Your vault is a Git repository of readable records and a dated ledger. Inspect it, back it up, and take it with you.

2

Thoughtful reminders

Find overdue touchpoints and upcoming dates with a local check, based on the details you choose to keep.

3

Agents that can help

Embedded skills help your AI agents read and write your vault with a propose, confirm, and apply workflow — or connect them directly over MCP.

4

Your boundaries

Mark a record no-ai to keep it out of agent-facing reads. The files themselves remain readable on disk.

5

Use it your way

Work from the command line, the terminal interface, or an agent. Sync through a private Git remote if you choose.

6

Open source

Built in Rust and available under Apache-2.0. Confidant has no server holding your vault.

How it works

Make room to remember.

1

Set up Confidant

Install the CLI and terminal UI yourself, or let your agent help with the setup.

confidant setup --agent auto
2

Make a vault

Create a local Git repository for your records. Keep it on an encrypted device and use a private remote if you sync.

confidant init --create
3

Keep in touch

Add people and log touchpoints as life happens. Check for the connections and dates that need attention.

confidant check

A little help, right when you need it

Make the next connection.

A check can bring the people you care about back to mind.

confidant — your terminal
# See who might appreciate a hello
$ confidant check
A touchpoint is overdue · a birthday is coming up

# Keep a record after you reach out
$ confidant log touch "Robin Example" text

# Fix a mistake without erasing history
$ confidant retract "Robin Example" --line 2026-09-14 --reason "logged under the wrong person"

Privacy, in plain language

Know where your memory lives.

Your vault is yours to keep. It is also readable by anyone who can access its files.

Confidant stores records as plaintext in a Git repository, including its history. Use full-disk encryption on trusted devices and a private remote if you sync. Confidant does not add its own encryption layer.

There is no Confidant server storing your vault. You can inspect the open-source code and the files yourself.

  • On your deviceKeep your vault on a trusted, encrypted machine.
  • Private remoteAnyone with access to your Git repo can read its records and history.
  • Agent boundariesno-ai excludes marked records from agent-facing reads; it does not encrypt them.
  • Files you ownPlain text and Git make your memory portable and inspectable.

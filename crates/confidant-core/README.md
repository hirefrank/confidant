# confidant-core

Parsing, modeling, derived values, and the check engine for
[Confidant](https://github.com/hirefrank/confidant) vaults. This is the
library crate behind the `confidant` CLI — it reads the vault file format
([spec/0.1.md](https://github.com/hirefrank/confidant/blob/main/spec/0.1.md)),
derives values (balances, session gaps, billing tags), and runs
`confidant check`.
